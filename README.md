# Yungiy Portfolio

차량 SW 검증 엔지니어 **양윤기**의 개인 포트폴리오입니다. OTA 기능 검증, CAN·DLT 로그 분석, 테스트 자동화, 전장부품 EOL 검사 경험을 소개합니다.

## 🔗 Link

[배포된 사이트 보러가기 (yungiy-portfolio.vercel.app)](https://yungiy-portfolio.vercel.app)

## 주요 구성

- 차량 SW 검증 경험과 사용 기술 정리
- 웹 프로젝트의 발표 자료 및 시연 영상 뷰어
- 반응형 화면, 다크 모드, 스크롤 위치에 따른 탐색 메뉴 표시

## 기술 스택

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS

## 로컬 실행

macOS Terminal 또는 Linux 셸에서 실행합니다.

```bash
# 패키지 설치
npm install

# 개발 서버 실행
npm run dev
```

프로덕션 빌드는 `npm run build`로 확인할 수 있습니다.
